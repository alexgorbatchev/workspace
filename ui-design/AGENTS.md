# UI & Design Systems

Monospace design systems, React/Tailwind component libraries, and visual canvas tools.

Inherits all standing workspace boundaries, code coverage requirements (90%), and Git conventions from the [parent monorepo AGENTS.md](../AGENTS.md).

## Local commands
- Status overview: `just status`
- Run checks across UI packages: `just check`
- Run tests across UI packages: `just test`

## Member repositories
- `dedent-string/` -> TypeScript template literal indenter and interpolation normalizer
- `mouseless-grid-editor/` -> Keyboard-driven grid editor for mouseless.click
- `shadcn/` -> Sharp monospace React component library built on shadcn and Base UI with Tailwind CSS v4 themes
